# Искра

Браузерный редактор диалогов и локаций поверх изображений.

## Запуск

Откройте index.html в современном браузере. Загрузите кадры кнопкой или вставьте картинку из буфера сочетанием Ctrl+V. Текст можно редактировать прямо на предпросмотре: нажмите на надпись и печатайте. Для каждого кадра можно настроить положение, ширину, завиток и масштаб оформления; диалог и локацию можно включать отдельно. Текущий кадр можно скачать или скопировать как PNG, а выбранные кадры сохранить ZIP-архивом.

## Локальные данные

Изображения не покидают браузер. Быстрые имена и настройки каждого кадра хранятся в localStorage. Настройки кадра восстанавливаются при повторном выборе того же файла с тем же именем, размером и датой изменения. Картинки после закрытия вкладки нужно загрузить заново.

Проект статический и подходит для GitHub Pages.

Копирование PNG в буфер обмена доступно при работе через HTTPS, в том числе на GitHub Pages. Для локальной работы браузер может ограничить доступ к буферу.
